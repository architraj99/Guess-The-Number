
# Guess The Number 

Guess The Number is a cool  mini game built by me for beest.

The goal of the game is simple......the player has to guess a secret number generated randomly by the system within a limited number of attempts.
After every guess, the game provides feedback like “Too High” or “Too Low” to help the player move closer to the correct answer....

it also includes live statistics tracking.... and restart function....


# Features

- Random number generation according to the level you choose
- Easy , Medium, and Hard difficulty modes
- after every move theres a live move counter ( 0/10)
- theres also hint system where you will be told wether the number is too loww or too high
- Restart game option so that you can escape frustation haha
- dark mode 
- Smooth animations 


# Tech Used

- Html
- css
- Java


# How To Play

1. Select a difficulty mode from the above menu.
2. Enter your guessed number inside the box 
3. Click the “Check Guess” button...
4. The game will tell whether your guess is too high or too low.
5. Continue guessing until you find the correct number.
6. You only get limited attempts... like 10 attempts so guess carefully.
7. Use the restart button to play again after winning or losing.


# Difficulty Modes

The game includes multiple difficulty levels to make gameplay more interesting.

- Easy Mode =  Number between 1 to 50
- Medium Mode = Number between 1 to 100
- Hard Mode = Number between 1 to 200
